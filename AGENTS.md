# Project continuation

Read `HANDOVER.md` completely before changing this project. It records the
current architecture, security requirements and validation commands.
`GRAPH_REBUILD_PLAN.md` is the historical rebuild specification;
`IMPLEMENTATION_DELTA.md` is the current source of truth for what landed,
deviations and remaining audit items.

Never commit uploaded agreements, generated session data, `data/library/`
(the persistent agreement families, which hold real uploaded documents), `.env`
files, API tokens or the OpenText source PDFs.

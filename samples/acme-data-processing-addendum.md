# Acme Data Processing Addendum

Version 1.0

Effective 15 February 2026

This fictional Data Processing Addendum applies when Provider processes
Personal Data in Customer Data to provide the Cloud Service.

1. Processing Instructions

Provider must process Personal Data only on Customer's documented instructions
unless applicable law requires different processing.

Customer must ensure that its instructions comply with applicable data
protection law and that it has a lawful basis for the processing.

2. Security

Provider must implement appropriate technical and organisational security
measures to protect Personal Data against accidental or unlawful destruction,
loss, alteration, disclosure or access.

Provider must notify Customer without undue delay after confirming a Personal
Data breach affecting Customer Data.

3. Subprocessors

Provider may appoint a Subprocessor, provided that Provider gives advance
notice and imposes data-protection obligations that are no less protective
than this Addendum.

4. Return and Deletion

At the end of the Cloud Service, Provider must return or delete Personal Data
unless applicable law requires retention.

5. Precedence

If there is a conflict concerning the processing of Personal Data, this Data
Processing Addendum prevails and controls over the Order Schedule and the
Cloud Master Agreement.
